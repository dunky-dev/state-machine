# @sandbox/uniffi

The sandbox palette written in Rust (`crates/uniffi`) as a React Native turbo module,
generated by [uniffi-bindgen-react-native](https://github.com/jhugman/uniffi-bindgen-react-native)
(ubrn). `sandbox/native` depends on it; Expo autolinks it into the dev build.

Only `package.json` and `ubrn.config.yaml` are source. Everything else is generated:

```bash
pnpm --filter @sandbox/uniffi ubrn:ios   # Rust for the iOS simulator + C++/TS glue
cd sandbox/native && pnpm ios            # an Expo dev build (not Expo Go)
```

Android is out of scope for now: the config builds the simulator target only.
